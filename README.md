# 🐍 مارِ شب‌تاب

یک نسخه‌ی مدرن و زیبا از بازی کلاسیک مار با گرافیک خیره‌کننده، افکت‌های صوتی و حالت‌های مختلف بازی

## ✨ ویژگی‌ها

### 🎮 هسته‌ی بازی
- **زمین ۲۱×۲۱** با موتور tick ثابت و بافر ورودی برای چرخش‌های سریع
- **جلوگیری از بازگشت ۱۸۰ درجه** برای تجربه‌ی بازی روان‌تر
- **چهار سطح دشواری**: آسان، متوسط، سخت و جهنمی
  - هر سطح با سرعت پایه، شتاب و سقف سرعت متفاوت
  - هر شکار مار را تندتر می‌کند
- **سه حالت بازی**:
  - 🎮 **کلاسیک**: بازی معمولی بدون محدودیت زمانی
  - ⏱️ **حمله زمان**: بیشترین امتیاز در ۲ دقیقه
  - 💀 **بقا**: تا چه مدت زنده می‌مانید؟

### 🌟 شب‌تاب‌ها و آیتم‌ها
- **شب‌تاب معمولی**: ۱۰+ امتیاز
- **شب‌تاب طلایی**: ۳۰+ امتیاز که هر ۵ شکار ظاهر می‌شود
  - حلقه‌ی شمارش معکوس برای محدودیت زمانی
  - فقط چند ثانیه باقی می‌ماند
- **آیتم‌های قدرت (Power-ups)**:
  - 🟢 **Slow**: کاهش سرعت مار به مدت ۱۰ ثانیه
  - 🟡 **Double**: دو برابر شدن امتیازها به مدت ۱۰ ثانیه
  - 🔵 **Shield**: محافظت از برخورد با بدن خود (یک بار مصرف)
  - 🟣 **Ghost**: عبور از دیوارها به مدت ۱۰ ثانیه

### 🎯 سیستم کمبو
- با خوردن غذاهای متوالی بدون وقفه، کمبو افزایش می‌یابد
- حداکثر کمبو ثبت می‌شود
- کمبو بالا باعث افتخار بیشتر است!

### 🎨 گرافیک و جلوه‌های بصری
- رندر Canvas با کیفیت بالا
- مار گرادیانی (سر لایم تا دُم زمردی)
- چشم‌های جهت‌دار که به سمت حرکت نگاه می‌کنند
- هاله‌ی نورانی دور مار
- شبکه‌ی شطرنجی ظریف
- افکت وینیت (تاریکی لبه‌ها)
- **افکت‌های سبک**:
  - انفجار ذره هنگام خوردن غذا
  - موج حلقه‌ای (Ripple effect)
  - متن شناور «+۱۰» و «+۳۰»
  - لرزش صفحه هنگام برخورد
  - چشمک قرمز هنگام مرگ
  - نمایش آیتم‌های قدرت با رنگ‌های مخصوص

### 🎹 کنترل‌ها

#### دسکتاپ
| عملکرد | کلیدها |
|--------|--------|
| حرکت مار | جهت‌نماها ↑↓←→ یا WASD |
| مکث / ادامه | Space یا P |
| شروع دوباره | Enter یا R |
| قطع/وصل صدا | M |

#### موبایل
- **حالت لمسی**: سُویپ روی زمین بازی
- **حالت دسته**: دکمه‌های جهت (D-pad) با دکمه‌ی مکث در مرکز
- **حالت کیبورد**: جهت‌نمای مجازی
- توقف خودکار هنگام خروج از تب

### 🏆 امتیازدهی و رابط کاربری
- **HUD پویا** با انیمیشن pop برای امتیاز
- نمایش زنده‌ی:
  - امتیاز فعلی
  - بهترین رکورد
  - طول مار
  - ضریب سرعت
  - زمان باقی‌مانده (در حالت حمله زمان)
  - زمان بقا (در حالت بقا)
  - کمبو فعلی و حداکثر کمبو
- اعداد فارسی در تمام رابط
- **رکورد جداگانه برای هر دشواری و حالت بازی** در localStorage
- نشان درخشان «رکورد جدید!» هنگام شکستن رکورد

### 🎵 سیستم صوتی
- افکت‌های WebAudio با کیفیت:
  - صدای خوردن غذا
  - صدای پاداش (شب‌تاب طلایی)
  - صدای آیتم قدرت (هر نوع صدای مخصوص خود را دارد)
    - Slow: صدای آرام و پیوسته
    - Double: صدای سریع و شاد
    - Shield: صدای سه‌نتی محافظتی
    - Ghost: صدای روح‌وار با glide
  - صدای کمبو (برای کمبوهای ۵ و ۱۰+)
  - صدای اخطار زمان (۱۰ ثانیه پایانی در حالت حمله زمان)
  - صدای باخت
  - صدای رکورد جدید
  - صدای رابط کاربری
- کلید قطع/وصل صدا (M)
- حالت بی‌صدا با ذخیره‌سازی در localStorage

### 🌌 اتمسفر و محیط
- پس‌زمینه‌ی جنگل شب با سه هاله‌ی نوری متحرک (Drifting)
- شبکه‌ی نقطه‌ای ظریف
- ۹ شب‌تاب چشمک‌زن شناور در پس‌زمینه
- اورلی‌های شروع/مکث/پایان با تایپوگرافی Lalezar
- پنل کناری برای:
  - انتخاب دشواری
  - انتخاب حالت بازی
  - مشاهده‌ی رکوردها
  - راهنمای کنترل

## 🚀 نصب و اجرا

### روش اول: اجرای با Node.js (توسعه)

#### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm یا yarn

#### مراحل نصب

```bash
# کلون کردن مخزن
git clone <repository-url>
cd <project-directory>

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه‌ی تولید
npm run build

# بررسی تایپ
npm run typecheck
```

### روش دوم: اجرای با XAMPP (ساده و سریع) ⭐

برای اجرای بازی بدون نیاز به Node.js و فقط با استفاده از XAMPP:

#### مراحل اجرا:

1. **کپی فایل‌ها به XAMPP**
   - پوشه `dist/` را کپی کنید به مسیر:
   ```
   C:\xampp\htdocs\snake-game\
   ```

2. **اجرای Apache**
   - XAMPP Control Panel را باز کنید
   - دکمه **Start** کنار **Apache** را بزنید

3. **اجرای بازی در مرورگر**
   - برای نسخه ساده (تست سریع):
   ```
   http://localhost/snake-game/play.php
   ```
   - برای نسخه پیشرفته (Production):
   ```
   http://localhost/snake-game/index.php
   ```

#### 📋 مستندات بیشتر:
- [راهنمای سریع شروع با XAMPP](RAPID_START_XAMPP.md) - راه‌اندازی در ۳ دقیقه
- [راهنمای کامل نصب در XAMPP](dist/README-XAMPP.md) - جزئیات کامل

#### مزایای اجرای با XAMPP:
- ✅ بدون نیاز به نصب Node.js
- ✅ اجرای سریع و آسان
- ✅ مناسب برای تست و نمایش
- ✅ سازگار با تمام نسخه‌های PHP 7.4+
- ✅ بدون نیاز به تنظیمات اضافی

## 🎯 قوانین بازی

1. **هدف**: جمع‌آوری شب‌تاب‌ها برای کسب امتیاز
2. **قانون اصلی**: به دیوارها یا بدن خودتان برخورد نکنید (مگر با آیتم Ghost)
3. **رشد**: با هر شب‌تاب، مار بلندتر و سریع‌تر می‌شود
4. **شب‌تاب طلایی**: هر ۵ شکار ظاهر می‌شود و فقط ۶.۵ ثانیه باقی می‌ماند
5. **آیتم‌های قدرت**: به صورت تصادفی (۱۵٪ شانس) پس از خوردن غذا ظاهر می‌شوند
6. **کمبو**: با خوردن غذاهای متوالی بدون وقفه، کمبو افزایش می‌یابد
7. **پایان بازی**: برخورد با دیوار یا بدن مار = باخت (مگر با آیتم‌های محافظتی)

## 💾 ذخیره‌سازی

بازی از `localStorage` مرورگر برای ذخیره موارد زیر استفاده می‌کند:
- بهترین رکورد برای هر سطح دشواری و حالت بازی
- سطح دشواری انتخاب‌شده
- حالت بازی انتخاب‌شده
- وضعیت قطع/وصل صدا
- شیوه‌ی کنترل انتخاب‌شده (لمسی/دسته/کیبورد)

کلیدهای ذخیره‌سازی:
- `shabtab-best-{difficulty}-{mode}`: رکوردها
- `shabtab-diff`: سطح دشواری
- `shabtab-mode`: حالت بازی
- `shabtab-muted`: وضعیت صدا
- `shabtab-control`: شیوه کنترل

## 🔧 توسعه

### ساختار پروژه (نسخه React/TypeScript)
```
├── src/
│   ├── components/
│   │   └── SnakeGame.tsx    # کامپوننت اصلی بازی
│   ├── game/
│   │   ├── engine.ts        # موتور بازی و منطق
│   │   └── audio.ts         # سیستم صوتی
│   ├── App.tsx              # کامپوننت اصلی برنامه
│   ├── main.tsx             # نقطه ورود
│   └── index.css            # استایل‌های سفارشی
├── index.html               # HTML اصلی
├── package.json             # وابستگی‌ها
├── tsconfig.json           # تنظیمات TypeScript
└── vite.config.js          # تنظیمات Vite
```

### ساختار پروژه (نسخه PHP/XAMPP)
```
├── dist/
│   ├── index.php            # نسخه پیشرفته با لود داینامیک
│   ├── play.php             # نسخه ساده برای تست سریع
│   ├── README-XAMPP.md      # راهنمای نصب در XAMPP
│   ├── assets/
│   │   ├── index-xxxx.js    # فایل JavaScript بهینه‌شده
│   │   └── index-xxxx.css   # فایل CSS بهینه‌شده
│   └── *.php                # فایل‌های PHP کمکی
├── RAPID_START_XAMPP.md     # راهنمای سریع شروع
└── README.md                # این فایل
```

### اسکریپت‌های npm (فقط نسخه توسعه)

```bash
npm run dev       # اجرای سرور توسعه
npm run build     # ساخت نسخه تولید → خروجی در پوشه dist/
npm run typecheck # بررسی تایپ TypeScript
```

### نحوه ساخت نسخه XAMPP

```bash
# ساخت نسخه production
npm run build

# کپی به XAMPP
cp -r dist/ C:/xampp/htdocs/snake-game/

# یا در ویندوز با PowerShell:
Copy-Item -Path dist -Destination C:\xampp\htdocs\snake-game -Recurse
```
